# Software-Construction-Development

This repository is organized to keep **all assignments, the project work, and all related tasks** for this subject in one place.

## Repository Structure

- `Assignments/` — assignment submissions and supporting files
- `Project/` — subject project implementation and deliverables
- `Tasks/` — task-wise work, notes, or checkpoints

## Notes

- Add each new assignment in `Assignments/`.
- Keep project files in `Project/`.
- Track individual task work in `Tasks/`.
